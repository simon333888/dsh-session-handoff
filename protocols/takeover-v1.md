# 会话接手协议 v1（takeover-v1）

> 本文件是人类可读版；运行时注入的接手首条消息由客户端 bundle 内嵌的同构模板生成。
> 协议独立版本化（v1, 2026-09-04）——菜单/机械层失效时，本协议可手动粘贴使用（降级通道）。

## 目标

新会话接手老会话的全部工作状态：记忆、习惯、任务、铁律（结构化 100% 保真），
上下文保持轻量（不携带原始对话，经 readback 脚本按需回溯）。

## 注入的接手首条消息（模板）

```
【会话接手协议 v1】你是接手会话。前一会话（{OLD_ID}，标题「{OLD_TITLE}」，工作区 {CWD}）
已将其工作移交给你。按序执行，禁止跳步；全程只使用工作区目录与 readback 脚本，不做任何
其他副作用操作（除写交接包外不得改动仓库文件）。

1. 建立记忆索引：运行
   python "{READBACK}" index {OLD_ID}

2. 读取全部关键内容（超长会话先 index 后定向 read/search，控制读取量）：
   - 所有任务及其状态（含最后 todo 状态与待用户确认项）
   - 关键决策及其理由、已证伪的假设、证据指针（文件路径/SHA/测试结果）
   - 对话中积累的临时纪律/习惯（AGENTS.md 之外的）
   - 未闭环动作（改到一半的文件、运行中的进程、持有的锁）

3. 在 {CWD}\.handoff\{HANDOFF_DIR}\ 下写八节交接包（每节一个 md 文件，内容务必具体）：
   01-identity.md 身份与使命（本会话角色/服务对象/关联会话）
   02-rules.md   铁律与习惯（AGENTS.md 等文件指针 + 对话中积累的临时纪律逐条枚举）
   03-tasks.md   任务清单及状态（完成/进行中/阻塞含原因/待用户确认）
   04-facts.md   事实与决策台账（结论+理由+证据指针；已证伪假设必须保留）
   05-baseline.md 工作区基线（git branch、git status --porcelain 摘要、
                   git stash create 生成的零副作用回退点 hash——只建对象不动工作区）
   06-open.md    未闭环动作清单
   07-next.md    下一步（最先做的 3 件事，具体到命令/文件）
   08-loss.md    信息丢失声明（哪些记忆没有写进包、会丢失——强制自审）

4. 运行校验并记录输出：
   python "{READBACK}" verify {CWD}\.handoff\{HANDOFF_DIR}

5. 复刻度自检（写进最终回复）：逐字复述 02 的铁律清单、逐项复述 03 的任务状态、
   点名 04 中至少 3 个关键证据指针。

6. 最终回复（严格格式，其后不得再有任何内容）：
   成功 → 第一行：我已经成功接替了工作，请指示。
          第二行：HANDOFF-MANIFEST: <verify 输出的目录>|01..08 齐备|sha256=<16位>
   任一步失败 → 仅一行：工作交接失败（附一行原因）

之后静默，等待用户下一步指令。
```

## 看门狗判定（插件侧）

| 条件 | 判定 |
| --- | --- |
| 末条 assistant 消息（归一化后）含成功话术 + HANDOFF-MANIFEST 行 | 成功 |
| 含"工作交接失败" | 失败（agent 自报） |
| 回合结束（发送钮恢复可用）且两句话均无 | 失败（协议违规，秒级判定） |
| 超时（默认 10 分钟，可配置） | 失败：取消在飞回合 + toast 补发 |

归一化 = 剥离 markdown 记号（* # > ` _ ~）与全部空白后做包含判断。

## 预设语义（P2-3 = B，尽力继承 + 声明回退）

新会话经 startSession 创建：若老会话预设 == 工作区默认预设 → 天然继承；
否则客户端尽力 noteAgentPreset 标注，且协议要求 08-loss.md 中声明
"预设未物理继承（老会话预设 X，本会话 Y）"的偏差。

## v0.2.x 补充：预设选择与命令纪律

- 移交点击后先弹**原生预设 roster**（方案 B）由用户点选，选中后协议首条消息自动附带
  "本会话已由用户指定预设「X」"；未选/直接开始则无此句，08-loss.md 声明偏差。
- 协议中的 readback 命令要求**原样复制执行**（直接用 python，禁止用 PowerShell 改写路径）——
  2026-09-04 首次实测中 agent 曾绕路排障，v1.1 模板已加硬性指引。

## 降级通道

菜单项不可用时（宿主结构变化/清扫器）：手动新建会话，粘贴本协议模板，
把 {OLD_ID}/{CWD}/{HANDOFF_DIR}/{READBACK} 四个占位符填实即可人工触发同一流程。
